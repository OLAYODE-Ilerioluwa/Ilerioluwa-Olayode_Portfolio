# Corco - Application Web

> Application web moderne développée avec React, TypeScript et Tailwind CSS, intégrant un système de navigation par composants et des pages dynamiques (Accueil, Actualités, Connexion, etc.).

## 🚀 Fonctionnalités
- **Navigation dynamique** : Basculement fluide entre les différentes vues (Accueil, À propos, Actus, Connexion).
- **Interface stylisée** : Design moderne et responsive grâce à **Tailwind CSS**.
- **Formulaire de connexion** : Composant de login centré avec effets de survol et validation.
- **Architecture modulaire** : Organisation claire des composants dans le dossier `src/pages/`.

## 🛠️ Technologies utilisées
- **React** (avec Vite)
- **TypeScript**
- **Tailwind CSS**
